# CLAUDE.md — инструкции для Claude Code

## О проекте

AI Song Builder — веб-приложение для совместного написания песен человеком и AI. Цель и критерии качества описаны в `GOAL.md`, структура — в `STRUCTURE.md`. Читай их перед любой задачей.

Приложение — соавтор, а не генератор. AI предлагает варианты, человек выбирает. Не превращай функции в «сгенерировать песню целиком».

## Стек (не менять без согласования)

- Frontend: React, TypeScript, Vite, TailwindCSS, shadcn/ui. Frontend отвечает за интерфейс, редактор, sidebar, взаимодействие с AI, autosave, copy/export.
- Backend: Python, FastAPI, SQLAlchemy, PostgreSQL. Backend отвечает за auth, CRUD песен, autosave, AI-запросы, сборку контекста песни, валидацию ответов AI, подготовку экспорта.
- Инфраструктура: Docker Compose (frontend, backend, postgres), данные PostgreSQL в Docker volume.

Запрещено без явного согласования: Redis, Celery, RabbitMQ, Kafka, microservices, векторные БД, LangChain, сложная agent-архитектура, CQRS, DDD.

## Правила работы с кодом

- Backend маленький и понятный. Не создавай архитектуру ради архитектуры. Файл разделяй только когда он действительно большой.
- Модель данных — только таблицы `songs` и `messages`. Не добавляй таблицы sections, lines, words, hooks, effects, styles, genres без необходимости.
- Контекст песни (тема, жанр, BPM, emotion, структура, уже написанный текст) передаётся AI автоматически. Пользователь не должен повторять описание трека.
- AI не оптимизирует текст только ради рифмы. Приоритет: смысл → эмоция → естественность языка → ритм → рифма.
- Жанровые правила (rap, pop, R&B, rock и т.д.) — это контекст, а не захардкоженные ограничения. Не делай логику завязанной на рэп.
- Vocal- и performance-подсказки (`[DOUBLE]`, `[ADLIB]`, `[ECHO]` и т.д.) — только рекомендации. Не реализуй обработку звука.

## Качество текстов, которые генерирует AI

Избегать: бессмысленных метафор, одинаковых конструкций, пафоса, случайных рифм, литературности там, где нужна разговорная речь, повтора одной мысли разными словами, клише без причины.

## Секреты и окружение

- Переменные окружения: `ADMIN_EMAIL`, `ADMIN_PASSWORD`, `SESSION_SECRET`, ключ AI-провайдера.
- Значения не коммитить, не печатать в логах и выводе. В репозитории только `.env.example`.
- Регистрации нет, приложение приватное.

## Проверки перед завершением задачи

- Backend: линтер и тесты, которые есть в проекте.
- Frontend: сборка и линтер.
- Docker: `docker compose up -d --build` поднимает все три сервиса.
- Не отключай и не ослабляй падающие тесты.

## Общение

Все ответы и отчёты пользователю — на русском языке. Код, команды, пути и идентификаторы не переводить.
