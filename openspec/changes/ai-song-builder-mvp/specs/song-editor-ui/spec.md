## Purpose

Предоставляет интерфейс редактора текста песни с секциями, выделением строки или её части, панелью AI-действий, sidebar с анализом и автосохранением, позволяя пользователю полностью контролировать применение предложений AI.

## ADDED Requirements

### Requirement: UI-компоненты на базе shadcn/ui
Интерфейс SHALL строиться исключительно на компонентах библиотеки shadcn/ui (Button, Input, Textarea, Select, Tabs/Accordion, Dialog/Sheet/Popover, Card, Badge, Separator, Toast) поверх Tailwind, без собственных low-level UI-примитивов.

#### Scenario: Использование компонентов shadcn/ui
- **WHEN** разрабатывается любой элемент интерфейса (кнопка, поле ввода, панель, модальное окно, индикатор)
- **THEN** используется соответствующий компонент shadcn/ui, кастомизированный только через Tailwind-классы, а не новый самописный компонент того же назначения

### Requirement: Редактор текста с секциями
Интерфейс SHALL отображать текст песни, разбитый на секции (например, `[VERSE]`, `[CHORUS]`), с возможностью ручного редактирования текста внутри и между секциями.

#### Scenario: Отображение секций
- **WHEN** пользователь открывает песню с текстом, содержащим маркеры секций
- **THEN** интерфейс отображает текст, визуально разделённый по секциям

#### Scenario: Ручное редактирование текста
- **WHEN** пользователь печатает или удаляет текст в редакторе
- **THEN** интерфейс сохраняет изменения локально и передаёт их в автосохранение без вмешательства AI

### Requirement: Выделение строки или части строки
Интерфейс SHALL позволять выделить целую строку или произвольную часть строки для применения AI-действия.

#### Scenario: Выделение целой строки
- **WHEN** пользователь кликает на строку текста
- **THEN** интерфейс помечает строку как выбранную и показывает доступные AI-действия для неё

#### Scenario: Выделение части строки
- **WHEN** пользователь выделяет часть текста внутри строки
- **THEN** интерфейс сохраняет точные границы выделения для последующего AI-действия

### Requirement: Панель AI-действий над строкой
Интерфейс SHALL предоставлять панель действий (Variants, Continue, Rewrite, Rhyme, Flow, Vocal) для текущего выделения и отображать предложенные AI варианты для подтверждения пользователем.

#### Scenario: Запрос действия
- **WHEN** пользователь выбирает действие на панели для выделенной строки
- **THEN** интерфейс отправляет запрос на backend и отображает полученные варианты, не изменяя текст в редакторе

#### Scenario: Применение варианта
- **WHEN** пользователь выбирает один из предложенных AI вариантов
- **THEN** интерфейс заменяет выделенный текст выбранным вариантом в редакторе

#### Scenario: Отклонение предложений
- **WHEN** пользователь закрывает панель с предложениями, не выбрав вариант
- **THEN** текст песни остаётся без изменений

### Requirement: Sidebar с анализом и структурой
Интерфейс SHALL отображать в боковой панели текущий анализ песни (тема, жанр, эмоция, BPM, энергия, структура) с возможностью ручного редактирования каждого поля.

#### Scenario: Просмотр анализа
- **WHEN** песня содержит сохранённый анализ
- **THEN** sidebar отображает все поля анализа

#### Scenario: Ручное изменение поля анализа
- **WHEN** пользователь редактирует поле анализа в sidebar (например, жанр)
- **THEN** интерфейс сохраняет изменённое значение через автосохранение

### Requirement: Индикатор автосохранения
Интерфейс SHALL показывать пользователю текущий статус автосохранения (сохранение в процессе, сохранено, ошибка).

#### Scenario: Успешное автосохранение
- **WHEN** изменения в редакторе успешно сохранены на backend
- **THEN** интерфейс отображает индикатор "сохранено"

#### Scenario: Ошибка автосохранения
- **WHEN** запрос автосохранения завершается ошибкой
- **THEN** интерфейс отображает индикатор ошибки и не теряет несохранённые изменения в редакторе

### Requirement: Панель копирования под редактором
Интерфейс SHALL отображать под текстом песни на странице редактора отдельные кнопки копирования: текста песни (lyrics), style-подсказки выбранного пресета/трека и negative style-подсказки выбранного пресета/трека — каждая копирует только своё содержимое в буфер обмена.

#### Scenario: Копирование текста песни
- **WHEN** пользователь нажимает кнопку "скопировать текст"
- **THEN** интерфейс копирует актуальный текст песни (lyrics) в буфер обмена

#### Scenario: Копирование style-подсказки
- **WHEN** пользователь нажимает кнопку "скопировать стиль"
- **THEN** интерфейс копирует style_prompt текущего пресета или track_settings песни в буфер обмена

#### Scenario: Копирование negative style-подсказки
- **WHEN** пользователь нажимает кнопку "скопировать негативный стиль"
- **THEN** интерфейс копирует negative_style_prompt текущего пресета или track_settings песни в буфер обмена

#### Scenario: Копирование без выбранного пресета
- **WHEN** пользователь нажимает кнопку "скопировать стиль" или "скопировать негативный стиль" для песни без пресета и без заполненных track_settings
- **THEN** интерфейс копирует пустую строку без ошибки
