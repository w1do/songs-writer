## Purpose

Хранит песню пользователя (идею, текст, настройки трека, анализ) как единую сущность, обеспечивает её создание, чтение, автосохранение и экспорт без дополнительных вспомогательных таблиц.

## ADDED Requirements

### Requirement: Создание песни из идеи
Система SHALL создавать новую запись песни при получении от пользователя фразы, описания настроения или черновика текста (`idea`).

#### Scenario: Успешное создание песни
- **WHEN** пользователь отправляет непустой текст идеи
- **THEN** система создаёт запись `songs` с этим текстом в поле `idea`, пустым `lyrics` и возвращает идентификатор песни

#### Scenario: Пустая идея отклоняется
- **WHEN** пользователь отправляет запрос на создание песни с пустым или отсутствующим текстом идеи
- **THEN** система возвращает ошибку валидации и не создаёт запись

### Requirement: Чтение песни
Система SHALL предоставлять получение полного состояния песни (идея, текст, анализ, настройки трека, настройки генерации) по её идентификатору.

#### Scenario: Получение существующей песни
- **WHEN** авторизованный пользователь запрашивает песню по существующему идентификатору
- **THEN** система возвращает все сохранённые поля песни

#### Scenario: Запрос несуществующей песни
- **WHEN** пользователь запрашивает песню с несуществующим идентификатором
- **THEN** система возвращает ошибку "не найдено" без падения

### Requirement: Автосохранение изменений песни
Система SHALL сохранять изменения `lyrics`, `track_settings`, `analysis` и `generation_settings` песни при каждом автосохранении, не создавая новую запись.

#### Scenario: Автосохранение текста
- **WHEN** пользователь редактирует текст песни и срабатывает автосохранение
- **THEN** система обновляет поле `lyrics` существующей записи и время `updated_at`

#### Scenario: Частичное обновление настроек
- **WHEN** автосохранение присылает только часть полей (например, только `track_settings`)
- **THEN** система обновляет только присланные поля, не затрагивая остальные

### Requirement: Экспорт и копирование песни
Система SHALL предоставлять данные песни в виде, пригодном для копирования и экспорта пользователем (текст, style/performance-промпты, настройки генерации).

#### Scenario: Экспорт готовой песни
- **WHEN** пользователь запрашивает экспорт песни
- **THEN** система возвращает текст, style prompt, negative style, performance-рекомендации и generation settings в структурированном виде
