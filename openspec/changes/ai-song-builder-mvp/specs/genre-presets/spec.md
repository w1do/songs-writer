## Purpose

Хранит пресеты жанров (`presets`) как переиспользуемые JSON-шаблоны полного звукового стиля песни (жанр, BPM, энергия, style/negative style подсказки, сцена звучания, хуки, эффекты, даблы, аэры/адлибы, ревербы, голоса и стиль припевов), которые пользователь может выбрать перед написанием текста. Выбранный пресет определяет, под какой стиль пишется текст, и передаётся в AI-функции как контекст, а не как жёсткое ограничение логики.

## ADDED Requirements

### Requirement: Хранение пресета жанра
Система SHALL хранить пресет жанра как запись SQLAlchemy ORM-модели `Preset` с полями: `id`, `name`, `genre`, `bpm_min`, `bpm_max`, `energy`, `style_prompt`, `negative_style_prompt`, `sound_scene` (общая сцена/атмосфера звучания), `hooks_prompt` (подсказки по хукам), `effects_prompt` (эффекты: даблы, аэры/адлибы, ревербы и т.д. в виде текстовой подсказки или JSONB-структуры), `chorus_vocal_style` (голоса и стиль исполнения припевов), `description`, `created_at`, `updated_at`.

#### Scenario: Создание пресета
- **WHEN** администратор создаёт пресет с именем, жанром, диапазоном BPM и описанием сцены звучания/эффектов/хуков/голосов припева
- **THEN** система сохраняет запись `presets` со всеми переданными полями и возвращает её идентификатор

#### Scenario: Обязательные поля пресета
- **WHEN** запрос на создание пресета не содержит `name` или `genre`
- **THEN** система отклоняет запрос ошибкой валидации Pydantic и не создаёт запись

#### Scenario: Частично заполненный пресет
- **WHEN** пресет создаётся без указания `hooks_prompt`, `effects_prompt` или `chorus_vocal_style`
- **THEN** система сохраняет пресет с этими полями пустыми, не требуя их обязательного заполнения

### Requirement: Список и чтение пресетов
Система SHALL предоставлять получение списка всех пресетов и чтение одного пресета по идентификатору.

#### Scenario: Получение списка пресетов
- **WHEN** авторизованный пользователь запрашивает список пресетов
- **THEN** система возвращает все сохранённые пресеты, отсортированные по имени

#### Scenario: Запрос несуществующего пресета
- **WHEN** пользователь запрашивает пресет с несуществующим идентификатором
- **THEN** система возвращает ошибку "не найдено" без падения

### Requirement: Редактирование и удаление пресета
Система SHALL позволять обновлять и удалять существующий пресет жанра.

#### Scenario: Обновление пресета
- **WHEN** пользователь отправляет обновление полей существующего пресета (например, `bpm_min`/`bpm_max`)
- **THEN** система сохраняет изменённые поля и обновляет `updated_at`

#### Scenario: Удаление пресета, использованного в песне
- **WHEN** пользователь удаляет пресет, который ранее был выбран в песне
- **THEN** система удаляет запись пресета, а песня сохраняет ранее скопированные в `analysis`/`track_settings` значения без ссылки на удалённый пресет

### Requirement: Выбор пресета при создании или редактировании песни
Система SHALL позволять связать песню с пресетом жанра по его идентификатору при создании песни или в любой момент редактирования.

#### Scenario: Создание песни с пресетом
- **WHEN** пользователь создаёт песню и указывает `preset_id` существующего пресета
- **THEN** система сохраняет ссылку на пресет и использует его жанр/BPM/энергию как значения по умолчанию в `analysis` песни, которые пользователь может изменить вручную

#### Scenario: Создание песни с несуществующим пресетом
- **WHEN** пользователь указывает `preset_id`, которому не соответствует ни одна запись `presets`
- **THEN** система возвращает ошибку валидации и не создаёт песню

### Requirement: Пресет как контекст для AI, а не ограничение
Каждая AI-функция SHALL использовать выбранный пресет песни (если он указан) как дополнительный контекст промпта (жанр, типичный BPM, энергия, style/negative style подсказки), не ограничивая и не переопределяя логику генерации жёсткими правилами.

#### Scenario: Учёт пресета в промпте
- **WHEN** пользователь вызывает любое AI-действие для песни со связанным пресетом
- **THEN** система добавляет жанр, диапазон BPM, энергию, style/negative style подсказки, сцену звучания, хуки, эффекты (даблы, аэры/адлибы, ревербы) и стиль/голоса припевов пресета в контекст запроса к AI-провайдеру наряду с текущими данными песни

#### Scenario: Песня без пресета
- **WHEN** пользователь вызывает AI-действие для песни, не связанной ни с одним пресетом
- **THEN** система формирует контекст только на основе данных самой песни (idea, lyrics, analysis), без ошибки
