# AGENTS.md — правила для AI-агентов

Этот файл для любых агентов, которые работают с кодом проекта AI Song Builder. Перед задачей прочитай `GOAL.md`, `STRUCTURE.md` и `CLAUDE.md`.

## Статус проекта

Код приложения ещё не написан. Документы описывают цель и план. Реализацию начинать только после явного одобрения пользователя. Одобрение планирования или документации не означает одобрения написания кода.

## Что делать

- Работать малыми итерациями: одна задача — одно изменение.
- Перед изменением файла прочитать его целиком или релевантный раздел.
- Соблюдать структуру из `STRUCTURE.md`. Не создавать новые папки и слои без необходимости.
- Использовать только стек из `CLAUDE.md`: React, TypeScript, Vite, TailwindCSS, shadcn/ui, FastAPI, SQLAlchemy, PostgreSQL, Docker Compose.
- Проверять версии библиотек по актуальной документации перед использованием API.
- Для каждой функции AI учитывать контекст песни: тему, жанр, BPM, emotion, структуру и уже написанный текст.

## Чего не делать

- Не добавлять Redis, Celery, RabbitMQ, Kafka, microservices, векторные БД, LangChain, CQRS, DDD.
- Не создавать таблицы, кроме `songs` и `messages`, без явного запроса.
- Не писать текст песни вместо пользователя. AI предлагает варианты, пользователь выбирает.
- Не реализовывать обработку звука. Vocal- и performance-подсказки — только текстовые рекомендации.
- Не хардкодить жанровые правила как ограничения. Жанр — это контекст.
- Не коммитить и не выводить секреты (`ADMIN_PASSWORD`, `SESSION_SECRET`, ключ AI-провайдера).
- Не отключать, не пропускать и не ослаблять падающие тесты.
- Не выполнять `git commit` без явного запроса пользователя.

## Проверки

- Backend: линтер и тесты проекта.
- Frontend: сборка и линтер.
- Docker: `docker compose up -d --build` поднимает frontend, backend и postgres.
- Перед завершением задачи сообщить, какие проверки выполнены и каков их результат. Не утверждать, что проверка прошла, если её не запускали.

## Общение

Отчёты и вопросы пользователю — на русском языке. Код, команды, пути и идентификаторы не переводить.
