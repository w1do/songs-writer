# Деплой в Dokploy

Runbook описывает развёртывание AI Song Builder в Dokploy из одного Docker Compose приложения.

### Состав стека

- `postgres` — образ `postgres:16`, данные хранятся в volume `pgdata`.
- `backend` — FastAPI, порт 8000 доступен только внутри Compose-сети.
- `frontend` — nginx на порту 80 (только `expose`), проксирует `/api/` в `backend`.

Публичный доступ открывает Traefik Dokploy через домен, привязанный к сервису `frontend`.

### Требования

- Dokploy с доступом к репозиторию проекта.
- Домен, направленный на сервер Dokploy (в репозитории домен не хранится).
- Ключ AI-провайдера и пароль PostgreSQL.

### Переменные окружения

Задать во вкладке Environment приложения в Dokploy. Dokploy записывает их в `.env` рядом с `docker-compose.yml`.

```dotenv
POSTGRES_PASSWORD=
SESSION_SECRET=
ADMIN_EMAIL=
ADMIN_PASSWORD=
AI_API_KEY=
AI_BASE_URL=
AI_MODEL=
COOKIE_SECURE=true
```

- `POSTGRES_PASSWORD` обязательна: Compose не запустит стек без неё.
- `COOKIE_SECURE=true` обязательна для HTTPS, чтобы cookie сессии передавалась с флагом `Secure`.
- Значения секретов не записывайте в репозиторий, логи и чаты.

### Домен и HTTPS

1. Открыть приложение в Dokploy, вкладка Domains.
2. Добавить домен для сервиса `frontend`, порт `80`.
3. Включить HTTPS (Let's Encrypt).

### Деплой и перезапуск

- Первый запуск: нажать Deploy после заполнения переменных окружения.
- После изменения домена или переменных окружения выполнить redeploy.

### Бэкапы

- Включить в Dokploy scheduled backups для сервиса `postgres`.
- Проверить восстановление бэкапа на тестовой базе данных.
- Данные `pgdata` не попадают в git: репозиторий их не сохраняет, восстановить их можно только из бэкапов Dokploy.

### Известные риски

- Схема БД создаётся через `create_all`; миграций Alembic нет.
- Нет rate limit на `/auth/login` и AI-эндпоинты.
- Logout не отзывает токен: токен действует до истечения TTL (7 дней).
- Тестовые песни из локальной БД не переносятся в прод: удалить их вручную.

### Чеклист после деплоя

- Открыть домен: отображается экран входа по HTTPS.
- Войти под `ADMIN_EMAIL` и `ADMIN_PASSWORD`: вход работает.
- В ответе на вход есть заголовок `Set-Cookie` с атрибутом `Secure`.
- `/api/health` возвращает 200.
- `/api/presets` без сессии возвращает 401.
- Создать пресет и песню.
- При пустом `AI_API_KEY` AI-эндпоинты возвращают 502.

### Локальная разработка

Порты на хост больше не публикуются: `frontend` доступен только через `expose` для Traefik.
Для локальных проверок используйте compose override вне репозитория или `docker compose exec`.
